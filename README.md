# Oak & Ember Coffee Co.

Mobile demo app for a small Atlanta coffee company.

## Features
- Order drinks & beans
- Buy merch
- Leave reviews
- Chat with staff
- Collect stamps & points
- Add a card and pay (demo only — no real charges)

## Install as a mobile app (PWA)

1. Enable GitHub Pages for this repo:  
   Settings → Pages → Source: Deploy from branch `main` → Save.

2. Wait a minute, then open the live URL (e.g. `https://bckaraczewski-arch.github.io/oak-ember-coffee/`).

3. On iPhone (Safari):  
   Tap the Share button → **Add to Home Screen**.  
   The icon will appear and open full-screen like a native app.

4. On Android:  
   Chrome menu → **Install app** or **Add to Home screen**.

All data (cart, rewards, saved card, reviews, chat) stays in the browser on that device.
